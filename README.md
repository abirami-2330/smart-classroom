# 🏫 LearnX - Smart Classroom Management System

🔗 **Live Website:** https://learnxsmartclass.netlify.app/

## 📌 About the Project

LearnX is a web-based Smart Classroom Management
System designed to help students access classroom-related
information and learning resources through a single platform.

## 🎯 Project Objective

The objective of LearnX is to explore how web technologies
can improve classroom organization, student engagement,
and access to academic information.

## ✨ Features

- 👩‍🎓 Student Profile
- 📋 Attendance Tracker
- 📝 Assignment Submission
- 📢 Announcements
- 💬 Complaints Section
- 📅 Timetable
- 🤖 AI Smart Assistant

*Note: Features listed above should match the actual
functionality available in the application.*

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Firebase
